Suivi du déploiement de Windows LAPS avec PowerShell et Power BI

1. Introduction

Après le déploiement de Windows LAPS (Local Administrator Password Solution) au sein du groupe STS Composite , il m’a été demandé de poursuivre le projet jusqu’à son terme en mettant en place un suivi du déploiement. L’objectif était de savoir, site par site et unité d’organisation (OU) par unité d’organisation, combien de machines étaient effectivement couvertes par LAPS, et de pouvoir suivre cette évolution dans le temps.

Contexte

Windows LAPS est une solution permettant de renforcer la sécurité en gérant automatiquement les mots de passe des comptes administrateurs locaux. Une fois déployée via Active Directory et les GPO, la question restait : “Comment vérifier et prouver que le déploiement est bien effectif sur l’ensemble des postes de travail et serveurs ?”. C’est dans ce cadre que j’ai développé un script PowerShell d’audit et de reporting.

Conception du script PowerShell

Le script que j’ai réalisé s’exécute en parcourant l’Active Directory de manière hiérarchique :

  • Pour chaque site du groupe
  • Pour chaque OU (Organizational Unit) du site
  • Pour chaque machine contenue dans l’OU

Le script vérifie si LAPS est bien appliqué sur la machine. Les résultats sont ensuite agrégés dans un fichier CSV, contenant :

  • Le nom du site
  • Le nom de l’OU
  • Le nombre total de machines
  • Le nombre de machines avec LAPS actif
  • La date d’exécution du script

Automatisation et suivi

Afin d’assurer un suivi régulier, le script peut être exécuté de manière périodique, par exemple via une tâche planifiée. Chaque exécution génère un nouveau fichier CSV daté, permettant d’historiser l’évolution du déploiement.

Intégration avec Power BI

Pour rendre ces données lisibles et facilement exploitables par les responsables IT, j’ai relié le CSV généré par le script à un rapport Power BI. Cela a permis de créer des graphiques dynamiques montrant :

  • L’avancement du déploiement par site
  • Le détail par OU
  • L’évolution dans le temps

Ce tableau de bord graphique a offert une vue claire et instantanée de la couverture LAPS sur l’ensemble de l’infrastructure, facilitant ainsi la prise de décision et le suivi du projet.

Mon bilan personnel

Ce projet m’a permis de renforcer mes compétences en PowerShell et en administration Active Directory, tout en découvrant l’importance de l’automatisation dans la gestion des infrastructures IT. La création du rapport Power BI m’a également initié à la data visualisation, un aspect crucial pour communiquer efficacement les résultats techniques aux équipes non techniques.

En combinant ces outils, j’ai pu livrer une solution complète, de l’audit technique à la présentation visuelle, répondant parfaitement aux besoins de suivi du déploiement de LAPS.

Conclusion

Grâce à ce script PowerShell couplé à Power BI, le déploiement de Windows LAPS a pu être audité, suivi et validé efficacement. Ce projet m’a permis de renforcer mes compétences en automatisation, en administration Active Directory ainsi qu’en data visualisation. Il illustre parfaitement l’importance de lier des outils techniques (PowerShell) avec des solutions analytiques (Power BI) pour obtenir une vision globale, claire et exploitable.
